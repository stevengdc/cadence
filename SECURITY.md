# Security / Segurança

This is an early alpha. Keep it on a trusted network while authentication, dependency updates and upgrades receive further review. Web ports bind to localhost by default. Cadence does not manage your TLS, reverse proxy, VPN, firewall or identity provider.

Do not post credentials or private databases in public issues. Use GitHub private vulnerability reporting when available; otherwise report the affected component and request a private contact without publishing exploit details or personal data.

The application container has no Docker socket and does not provision or administer its host. Redistribution is explicit and tied to the current file signature. Back up state and media before importing or replacing an existing collection.

Versão alpha: usa uma rede de confiança. Não publiques credenciais nem bases de dados em issues. O Cadence não configura TLS, VPN, firewall, Proxmox ou o sistema operativo. Guarda cópias do estado e da música antes de importar ou substituir uma biblioteca.
